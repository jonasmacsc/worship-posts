# worship-posts

Artes do Instagram @jonas_maciel_worship. Repositório público: o Instagram baixa as imagens daqui.

- `posts/` — artes do feed (4:5)
- `stories/AAAA-MM-DD/` — stories diários (9:16)
- `stories/log.json` — histórico (evita repetir versículo)
- `tools/make_story.py` — gerador dos stories (`python3 -I tools/make_story.py SAIDA.jpg "Texto" "Referência" "RÓTULO"`)

Regra: nada é publicado sem aprovação do Jonas. Se uma arte for corrigida, use um novo nome de arquivo (o GitHub guarda cópia em cache por alguns minutos).
